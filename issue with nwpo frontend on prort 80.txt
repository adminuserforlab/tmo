It might be dropping the request. By default WAF will drop even if it's in learning mode. The easiest thing to try is to update this:

http-request deny if waf_WAF_Rule_nwpo_qa_drop || waf_WAF_Rule_nwpo_qa_block !waf_WAF_Rule_nwpo_qa_learning
waf-body http-request deny if waf_headers waf_WAF_Rule_nwpo_qa_drop || waf_headers waf_WAF_Rule_nwpo_qa_block !waf_WAF_Rule_nwpo_qa_learning

to this:

http-request deny if waf_WAF_Rule_nwpo_qa_drop !waf_WAF_Rule_nwpo_qa_learning || waf_WAF_Rule_nwpo_qa_block !waf_WAF_Rule_nwpo_qa_learning
waf-body http-request deny if waf_headers waf_WAF_Rule_nwpo_qa_drop !waf_WAF_Rule_nwpo_qa_learning || waf_headers waf_WAF_Rule_nwpo_qa_block !waf_WAF_Rule_nwpo_qa_learning

That way it won't drop when in learning mode. To confirm this is what is happening I'd need to see the WAF logs. Let me know what you'd like to do.
