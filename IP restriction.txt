ENG REPLY:
You need to block by hostname, right?

For example, all the names:
site1.velocitor.com , site2.velocitor.com, site3.velocitor.com
resolve to IP 172.16.55.20
but you want to deny only the requests that were addressed to site2.velocitor.com (allowing all the others: site1.velocitor.com and site3.velocitor.com). In that case:

--- begin ---
frontend PROD-WebFarm
...
bind 172.18.x.x:443 name 172.18.x.x:443 crt /var/lib/dataplaneapi/storage/certs/velsol-2026-full.pem ca-file /var/lib/dataplaneapi/storage/certs/velsol-2026-full.pem ssl strict-sni
http-request deny if { ssl_fc_sni -f /etc/hapee/blacklist.txt }
...
--- end ---

The file /etc/hapee/blacklist.txt will contain all the hostnames that you do not want to allow to access

The option strict-sni was added also to your bind line, that way "The SSL/TLS negotiation is allowed only if the client provided an SNI that matches a certificate". It will prevent requests like:
# curl https://172.16.55.20 --header 'Host: site2.velocitor.com'
to be accepted.

For reference:
- https://customer-docs.haproxy.com/haproxy-configuration-manual/new/3-0r1/#section-7.3.4.-sslfcsni
- https://customer-docs.haproxy.com/haproxy-configuration-manual/new/3-0r1/#section-5.1.-strict-sni

I propose you to use a file with this format:
domain01:IP01
each line means:
"requests for domain01 are not accepted when coming from IP01"

Example:
# cat /var/lib/dataplaneapi/storage/general/deny-list.txt
site3.velocitor.com:10.10.99.3

The configuration will look like:

--- begin ---
frontend PROD-WebFarm
...
bind 172.18.x.x:443 name 172.18.x.x:443 crt /var/lib/dataplaneapi/storage/certs/velsol-2026-full.pem ca-file /var/lib/dataplaneapi/storage/certs/velsol-2026-full.pem ssl strict-sni

http-request set-var(txn.src) src
http-request deny if !{ ssl_fc } { req.hdr(Host),lower,concat(":"),concat("",txn.src) -f /var/lib/dataplaneapi/storage/general/deny-list.txt }
http-request deny if { ssl_fc_sni,lower,concat(":"),concat("",txn.src) -f /var/lib/dataplaneapi/storage/general/deny-list.txt }

...
--- end ---
