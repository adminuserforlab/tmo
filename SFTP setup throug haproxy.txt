[EXTERNAL] SFTP Setup through HAProxy===========

I'm trying to setup an SFTP connection to be used by external collection agencies to access an internal SFTP server in our DMZ proxied though HAProxy.

I've changed the SSH port on the server to 2022, and am trying to use Port 22 for SFTP, I've tried Port 2222 as well.

I can see on the HAProxy server that it's listening on port 22. When I try to connect with FileZilla, I'm not establishing a connection, nothing shows in Report Explorer for my attempts.

I've setup WEBDAV to this same SFTP server so we can map drives in Windows clients on port 8090, and that's working fine.
I've verified that the traffic is allowed through our firewall. It doesn't seem like it's hitting the HAProxy server though.
My config for SFTP is
frontend SFTP_IN
mode tcp
bind *:22 name *.22
bind *:2222 name *.2222
option tcplog
default_backend DMZSFTP_22

backend DMZSFTP_22
description DMSSFTP Port 22
enabled
server DMZSFTP:22 172.30.30.11:22 check port 22 weight 10
Is there anything else I need to do to have SFTP pass through HAProxy using port 22?

My guess is that your issue was http mode was being inherited from the defaults section "default" where you set:
mode http

Given that, you had to explicitly set 'mode tcp' for the backend as well.
