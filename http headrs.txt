If your traffic is in HTTPS, you can add strict-sni on your bind line:
bind :443 ssl crt ... strict-sni
A request to a domain for HAProxy that does not have a certificate will be rejected at the TLS negotiation.

And for HTTP traffic, indeed the ACL "hdr(host) -i host1.example.com host2.example.com" will block them

Hello Stéphane,

In tcp mode, it is possible to retrieve and examine headers, but the overall syntax of the request will not be checked.

For example:
frontend tcp_fe
mode tcp
bind :80
tcp-request inspect-delay 5s # required to analyze the request before forwarding it
http-request deny if {req.hdr(my-header) } !{ req.hdr(my-header) -m reg "[A-z0-9_-]*" }

will reject any request that has the "my-header" header set but contains illegal characters.

To reject any invalid request, it is necessary to switch the proxy to http mode, non-compliant requests will be rejected with a 400 error automatically.
